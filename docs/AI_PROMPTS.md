# AI prompt design

Never ask the model to invent measurements.

Meal vision:
- identify foods
- estimate portion
- state uncertainty
- ask a clarification question if a high-impact ambiguity exists
- return structured JSON only

Coach:
- distinguish observed data from inference
- never claim medical diagnosis
- give at most 3 priorities
- explain why
- avoid punitive compensation after overeating
- respect travel/school/stage context
- use recovery to adjust training

Weekly:
- summarize trends
- detect plateau only with enough data
- propose small changes
- never make a large calorie jump from a single weigh-in
