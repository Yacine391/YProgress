# YProgress PWA V14

Installs on iPhone from Safari using Add to Home Screen.

Build:
npm install
npm run build:web

Deploy the resulting web output to an HTTPS host, then open it in Safari:
Share -> Add to Home Screen.

The PWA is independent of the development PC after deployment. Native HealthKit, WidgetKit and ActivityKit are intentionally kept behind bridge placeholders for a future native shell.
