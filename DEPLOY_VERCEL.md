# YProgress V14 — Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. Import the repository in Vercel.
3. Build Command: npm run build:web
4. Output Directory: dist
5. Deploy.
6. On iPhone, open the HTTPS URL in Safari → Share → Add to Home Screen.

The included vercel.json already contains the build/output settings.
Do not commit API keys; use Vercel Environment Variables for secrets.
